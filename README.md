Maze Solver Using BFS

A Python-based maze solver that uses the Breadth-First Search (BFS) algorithm to find the shortest path between a start point and an end point in a 2D maze. The solution path is displayed clearly within the maze grid.

Features
Represents the maze as a 2D grid
Uses BFS to find the shortest path
Displays the maze and solution path
Handles blocked paths and obstacles
Supports testing with different maze configurations
Technologies Used
Python
Breadth-First Search (BFS)
Queue (collections.deque)
